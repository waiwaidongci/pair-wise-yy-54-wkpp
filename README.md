# 市政道路施工封路方案协调与审批平台

源提示词编号：11。支持分段封路范围、施工阶段、绕行路线、车道收窄和临时设施的同一地图协作；检查相邻工程、救护通道、公交覆盖和绕行时延冲突；提供图层开关、路线绘制、阶段时间轴、条件会签、版本比较和公开通告包导出。

## 技术栈

Vue 3、Arco Design Vue、Pinia、Vue Router、Apollo Client、GraphQL、MapLibre GL、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

开发地址：http://localhost:62054

```bash
npm run build
```

## 协同与审批规则

- **三地同改**：地图、阶段计划（总览表格）、会签页改的是同一份权威数据，单条在线编辑即走 CAS 事务。
- **离线批次合并**：离线期间各单位改动按「现场批次」归集（一单位一个在途批次），回传时按字段做三方合并；同一阶段同一字段两边都改过 → 两份内容都保留、标出冲突，裁定前阶段显示「冲突待裁」。
- **并发不覆盖**：在线提交为对象级 CAS，两个窗口同提同一阶段时后到整批拒绝，先到值与服务端当前值回显，可 rebase 到最新修订号后整批重试。
- **失败整批重试 / 幂等**：批次为原子事务，弱网中断不写库；确认丢失（已落库）时重试命中批次结果表，回放首次结果，不重复写入。
- **冻结审批快照**：当前几何与已接受会签条件一致（四道闸门）才能冻结；地图、总览、公开通告统一按快照判断，冻结期间各处只读。
- **失效联动**：冻结后车道、绕行或应急条件一旦变化，原审批立即失效、已批准状态回退，需重新冻结；公开通告无生效快照禁止导出。

「批次与审批」页提供在线/离线切换、单位切换、一次性故障注入（弱网中断 / 确认丢失）与双窗口并发构造，便于走查上述规则。服务端以 localStorage 充当权威端，跨标签页通过 BroadcastChannel / storage 事件互拉。
